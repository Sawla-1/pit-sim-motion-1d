Static First Render - Detailed Component Breakdown
==================================================

1. App Component (Main Container)
---------------------------------
- Layout structure with CSS classes
- State initialization (simulation and data objects)
- Real-time Values Display (App):
  - x: 0.00 m (position)
  - v: 0.00 m/s (velocity) 
  - a: 0.00 m/s² (acceleration)
- Time Display (App):
  - 0 s (simulation time)
- Control Panel (App):
  - Parameters Inputs (App):
    - Position input: 0 (number input)
    - Velocity input: 0 (number input)
    - Acceleration input: 0 (number input)
  - Mode Selection (App):
    - "Record" radio button (selected)
    - "Playback" radio button (disabled)
  - Control Buttons (App):
    - Play button (▶)
    - Reset button
    - Clear button (disabled)

2. Simulation3D Component
-------------------------
- 3D Canvas (Simulation3D):
  - Orthographic camera
  - Ambient light
- Ground + Ruler + Sprite (Simulation3D):
  - Sky blue ground (50 units wide)
  - Green ruler markers (11 markers at even positions)
  - Red center line (0 meter marker)
  - Orange moving sprite at position 0
- Text Overlays (Simulation3D):
  - "0 meters" (red text, center)
  - "-10" (green text, left side)
  - "10" (green text, right side)

3. Charts Component
------------------
- Position Graph (Charts): Empty, shows only axes
- Velocity Graph (Charts): Empty, shows only axes
- Acceleration Graph (Charts): Empty, shows only axes
- Chart container with background styling
